# Painel do Gabinete

Página gerada automaticamente pelo dashboard do gabinete. Mostra, para cada
processo da caixa, com quem ele está, em que situação se encontra e quando
vence, além dos processos que saíram da caixa nos últimos 30 dias.

Não edite nada aqui: cada atualização do dashboard substitui todo o conteúdo
deste repositório, e só a situação atual fica guardada.
